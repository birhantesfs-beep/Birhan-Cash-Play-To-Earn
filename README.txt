# Birhan Cash - Loading + Home

This project combines the two supplied Birhan Cash screens.

## Files
- index.html
- style.css
- script.js
- assets/loading-screen.png
- assets/home-screen.png

## Run
Open `index.html` in a browser.

Flow:
1. Loading screen appears.
2. Progress bar runs automatically.
3. Home screen appears.
4. Play / Earn / Withdraw / Grow buttons show a toast.
5. Sign Up and Log In open a simple form modal.

The supplied images are used as the visual backgrounds so the result matches the provided reference screens closely.
